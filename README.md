# Rabbit Number Garden

A Cantonese parent-child number-play prototype for ages 4-5. React 19,
TypeScript and Vite; no backend, account, analytics or model API is required.
Adults select activities directly. There are no scores, timers or unlocks.

## Run

Use Node.js 24 LTS and npm. From the project directory:

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

Open http://localhost:5173/. The VS Code task `Rabbit Garden: local preview`
runs the same command. For an iPad on the same trusted Wi-Fi, use the computer's
LAN address with port 5173. Windows Firewall may require private-network access.
Do not expose the development server to the public internet.

## Playable In This Version

- Four foundations: counting, one-to-one matching/comparison, part-whole baskets
  including zero, and an exact two-by-five ten-frame. Parent selects 1-5 or 1-10.
- Number train (+1/-1 with preset starts), joining/removing/missing-part stories,
  and a separate parent-selected odd/even pairing activity from 0 through 20.
- Inspectable ten-unit bundles, forward decade bridges prioritizing 27 to 32,
  and a separately selected reverse route from 31 to 29.
- Two ten-frames for make-ten, unpacking subtraction, place-value orders,
  carrying and borrowing with finite tasks, including 30 minus 14.
- Undo, reset, pause/resume, hints, parent settings and local observation notes.
  Exchange conserves quantity; arithmetic tasks stay within 0-99.

Independent attempts hide relevant result readouts until confirmation. Hints or
unsuccessful checks change the attempt to assisted. These are concrete-object
activities, not standardized assessments. Completion does not establish mastery,
confidence, a diagnosis, or a child's spoken naming ability.

## Speech And Local Data

Only an available `zh-HK` browser voice is used. Voice discovery updates
asynchronously; old speech is cancelled when changing activities or modes.
No Mandarin fallback is substituted. A parent can read the visible prompt when
Cantonese speech is unavailable. Browser/OS speech services may have their own
network requirements; this app does not supply a voice model.

Versioned localStorage keeps settings and at most 60 observations, with no child
name or identity. Blocked/corrupt storage falls back to playable in-memory state.
The parent panel has a two-step clear control. Data is not synchronized; localhost
and a LAN URL are separate browser origins with separate records.

Fonts and nine original procedural PNG illustrations are bundled locally.
Artwork was generated by `node scripts/illustrations.mjs` using Sharp, not by an
AI image service. This is not yet an installable/offline PWA.

## Verification

```sh
npm test -- --run
npm run lint
npm run build
npx playwright install chromium webkit
npm run test:e2e
```

The build produces `dist/` for a static host. Playwright starts or reuses the
port-5173 server and tests Chromium and WebKit at 1440x900, 1024x768, 768x1024,
and 390x844. Coverage includes object conservation, undo, arithmetic boundaries,
decade transitions, privacy fallbacks, keyboard dialogs and touch selection.
Screenshots are written under `test-results/`.

Desktop WebKit and simulated touch are not real-iPad acceptance. Before using
with a child, check Safari portrait/landscape, actual touch, scrolling, Cantonese
pronunciation/volume, audio cancellation and storage on the intended iPad.
